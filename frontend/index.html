About Us

Sharp Shooter explores computer vision techniques for extracting shooting-form landmarks and basketball trajectories from video.

Analysis Pipeline

The current prototype combines MediaPipe pose estimation with a custom YOLOv5 basketball detector. See the repository README for command-line usage.

Responsible Research

Record and analyze only people who have given informed consent. Do not commit videos, pose datasets, or personal information to the repository.

Project Status

This is a research prototype. The static page is not yet connected to an analysis API.
